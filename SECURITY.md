# Security Policy

## Supported versions

Security fixes are applied to the latest `main` branch and the most recent tagged release.

## Reporting a vulnerability

Do not file a public GitHub issue for an unpatched vulnerability.

Report security issues privately with:
- a clear description of the impact
- affected versions or commit hashes
- reproduction steps or proof of concept
- any suggested mitigation

Until a dedicated private mailbox is published, use GitHub Security Advisories for private reporting when available on the repository.

## Response expectations

- Triage target: within 3 business days
- Initial remediation plan: within 7 business days for confirmed issues
- Coordinated disclosure after a fix is available and consumers have a reasonable upgrade path
